# ものさしハンター

ものさしの目盛を見て、はじまりからおわりまでの長さを読む学習アプリです。タブレットでの学習を前提に、問題・入力・答えの確認をシンプルにまとめています。

## 学習レベル

レベルと「はじまりの位置」は別の設定です。

- レベル1「cmまで」：1cmごとの目盛を読み、cmで答える
- レベル2「cmとmmまで」：1mmまで読み、cmとmmで答える
- レベル3「小数で表す」：1mmを0.1cmとして、小数で答える
- はじまりの位置「0から」：ものさしの0から始まる問題
- はじまりの位置「とちゅうから」：0ではない位置から始まり、2つの位置の差を考える問題

## ナビアン・モンスター

問題に登場するモンスターは、`TT-sensei/navi-character-` の `catalog.json` に登録されたグループ2を使用しています。

- レベル1：グループ2のナビアン
- レベル2：グループ2のエボナビ
- レベル3：グループ2のボスナビ

現在の素材はリポジトリ内に複製せず、公式GitHub上の素材を直接参照します。

## ナビアン図鑑

タイトル画面の「ナビアン図鑑」から、問題で出会ったモンスターを確認できます。

- ナビアン・エボナビ・ボスをまとめて収録
- 未発見のモンスターは「？？？」で表示
- 正解したときの出現モンスターを出会った回数としてlocalStorageに記録

## モード

- れんしゅう：時間制限なしで繰り返し練習
- タイム制 60秒：60秒間で何問正解できるかに挑戦

最高れんぞく正解数などの学習記録と設定は端末内に保存します。サーバーやデータベースは使用しません。

## 素材について

ナビアン・エボナビ・ボスの画像は `TT-sensei/navi-character-` の公式素材を参照します。画像が読み込めない場合はフォールバック表示に切り替わります。

外部依存は、学習UI/判定に使用する `edu-components` と `edu-effects` のGitHub Pages公開ファイルのみです。APIキーや有料API、バックエンド、データベースは使用しません。
